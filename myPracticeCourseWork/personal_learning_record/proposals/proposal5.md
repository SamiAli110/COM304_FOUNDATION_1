# Council Proposal 5
 
## Explanation of this proposal
This proposal suggests that the council adopt a formal policy to prioritize open source software OSS) when procuring new digital systems, applications, and tools. Open source software is defined by its publicly available source code, which can be inspected, modified, and redistributed under established open licences. Examples for this include Linux, LibreOffice, Firefox, and many more modern server technologies.

In contrast, proprietary software is closed source and typically requires paid licensing, subscription fees, and vendor-controlled support. While proprietary tools still have value in specialist areas, many councils and public sector bodies now use  open source software due to flexibility and transparency, and how cost-effective it is cost-effective.

Adopting open source solutions offers several advantages such as:
1. Cost reduction: OSS often has no licensing fees, reducing running costs.
2. Security transparency as code is open for inspection, and vulnerabilities can be found quickly by the global community
3. Avoiding vendor lock-in, the council will maintain flexibility and avoid dependency on any single commercial provider
Public sector organizations worldwide, including governments, schools, universities, and the NHS, are increasingly preferring open source as part of digital transformation strategies. This proposal suggests a " prefer open source first" approach where OSS is considered the default option unless there is a clear reason to select a proprietary alternative, for example, specialist software, legal obligations, or unique features and requirements.

## Initial Analysis of the Proposal
Preferring open source software offers financial, strategic, and technical benefits; it reduces dependency on commercial vendors and encourages long-term sustainability. However, the council must ensure OSS tools have adequate support options and meet accessibility, security and performance requirements. A procurement framework must be developed to evaluate OSS fairly against proprietary alternatives.
